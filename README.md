**แอปช่วยจัดการชีวิตประจำวัน**

**"วัตถุประสงค์"**

ผู้ใช้งานจัดการกิจกรรมและงานที่ต้องทำในแต่ละวันได้อย่างเป็นระบบ  
ช่วยบันทึกและติดตามรายรับ–รายจ่าย  
ผู้ใช้งานติดตามอารมณ์และพฤติกรรมของตนเองในแต่ละวัน  

**"กลุ่มเป้าหมาย"**

นักเรียน  
นักศึกษา  
วัยทำงาน  

**"ฟังก์ชันหลัก"**

จัดการตารางและการแจ้งเตือน  
บันทึกรายรับ-รายจ่าย  
บันทึกอารมณ์ประจำวัน  

**"เป้าหมายของระบบ"**

บริหารเวลาได้ดีขึ้น  
ควบคุมการทำงานและวงาแผนการใช้จ่ายได้ดีขึ้น  
รู้จักและติดตามอารมณ์ของตนเองได้อย่างสม่ำเสมอ
